# plaintext

Когда Шифры молчат, говорим открытым текстом.

Аварийная страница проекта на GitHub Pages: один HTML без скриптов и внешних запросов. `404.html` повторяет `index.html`, потому что Pages отдаёт его на любом несуществующем пути: посетитель видит страницу по любой ссылке.

Текст правится в `index.html`, затем `cp index.html 404.html`. Push в `main` публикует страницу примерно за минуту.
